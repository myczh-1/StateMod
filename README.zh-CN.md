# StateMod

**冻结语言模型的外置条件控制**

这是一个研究项目：现有结果支持有限的可行性，但尚未建立可靠的跨任务泛化。

外置判断模块读取冻结模型的隐藏状态，决定是否在 Python 返回表达式的首次决策处访问独立的 Latent KV Bank。判断模块不生成代码；Bank 通过 Attention 影响后续自然生成，不是输出替换。

[英文首页与架构图](README.md) · [中文完整报告](docs/TECHNICAL_REPORT.zh-CN.md) · [实验索引](experiments/README.md) · [复现范围](reproducibility/REPRODUCE.md)

| 实验 | 主要结果 | 定位 |
|---|---|---|
| Cloud03，8B | 自动 E 联合 8/8，N 合同 8/8，零新增功能退化 | 开发成功；6个计算族，包含重复措辞 |
| Cloud04，8B | 自动 E 联合 3/16，N 合同 3/16 | 新任务确认未通过；能力和合同设计问题并存 |
| Cloud06，8B | 人工/自动 E 联合 4/8；自动 N 合同 0/8 | 新族确认未通过；两次误启用，人工 V 也有计算退化 |
| Cloud10，14B | 文字选型 8/8；文字代码 E 4/4、N 4/4 | 开发文字能力；原无规则能力门槛的停止状态保留 |
| Cloud11 Attempt02，14B | 训练 8/8、留出措辞 7/8；N拒绝 3/4 | 拒绝保护未通过，未运行 V |
| Cloud12，14B | 布尔题换措辞后，有无围栏都会误启用 | 两题固定前缀诊断，不是独立确认 |

E 中合法 `set` 仍可能满足用户功能，只是没有执行外部 `frozenset` 偏好。N 则必须让调用者对返回对象实际增删。

仓库保留协议、输入、输出、评分、失败、数值记录与哈希；提供小型模块、原8B Bank及CPU离线重算脚本。不附主模型权重，不宣称已重新完成全流程GPU复现，也不拼接8B和14B的不同实验为成功闭环。
