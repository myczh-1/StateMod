# Limits of the evidence

- Cloud03 is development evidence from six computation families, not sixteen independent families. Later confirmation attempts did not pass.
- Cloud11's held-out wording uses the same four families as training. Cloud12 uses two already seen N tasks and controlled prefixes. Neither is independent task generalization.
- A correct E `set` can satisfy the user contract while missing the external preference. Do not call all such outputs semantic errors.
- Direct teacher type selection, complete code generation, module fidelity, routing and V function preservation are separate outcomes.
- 14B uses BF16 and 8B uses FP32. Teacher differences cannot identify a model-size effect alone. There is no 14B V-loop result in this release.
- Wording and token length/absolute position co-vary in Cloud12; its decomposition does not prove lexical-only shortcuts or absent semantic information.
- Side-KV slots, offline compilation and decision replay have costs. No total-cost reduction or universal zero-context claim is supported.
- The event detector reads generated Python text and is not a generic multilingual rule router. Single-return selection is not guaranteed for arbitrary generated programs.
- The focal loop studies do not include sufficient matched random/wrong-Bank controls or broad public benchmarks to establish method superiority.
- The restricted execution worker is not a security sandbox; it was used on bounded research outputs.
- Archived scores, outputs and selected arrays permit offline verification. A new full GPU rerun has not been performed for publication; all large tensors are not bundled and there is no public artifact download service yet.
- Historical failed states are preserved. Transport archives and local downloadable model weights were later removed under an authorized cleanup; extracted evidence was retained. An old archive hash is not a promise that the original archive container is still distributed.
- No production reliability, robust automatic multi-rule behavior, arbitrary persona/emotion control, or cross-model Bank reuse has been established.
