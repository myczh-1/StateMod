# Cloud08 八题任务与合同

四个已见开发族，八题同一合同表述；没有使用模型输出筛选。

## double_E_CLEAR

```text
编写 Python 函数 collect_doubles(numbers)，numbers 是整数列表，返回各整数乘以二后的不同值。
调用者在函数返回后只查询其中的成员，不会添加或移除成员。返回对象无需提供增删接口。函数只计算并返回结果，不在函数内部执行验收。
结果中不保留重复成员，成员顺序不限。不要修改输入。请将每个成员的计算和去重直接写在唯一的 return 表达式中，不要先创建结果变量再返回。只输出完整函数代码，不写注释、解释或辅助函数。
```

预期类型选择：frozenset；功能用例：
```json
[
  {
    "role": "empty",
    "args": [
      []
    ],
    "expected": []
  },
  {
    "role": "duplicates",
    "args": [
      [
        -2,
        2,
        2
      ]
    ],
    "expected": [
      -4,
      4
    ]
  },
  {
    "role": "boundary",
    "args": [
      [
        0,
        -1,
        100
      ]
    ],
    "expected": [
      0,
      -2,
      200
    ]
  }
]
```
