# StateMod Cloud12：冻结判断模块的措辞 × 代码格式交叉诊断

日期：2026-11-09。小型开发机制诊断；不是新训练、自然生成成绩或独立确认。

## 唯一问题

Cloud11 布尔取反 N 的误启用，是否在只改变措辞或只改变代码围栏时出现，以及两种变化是否交互。保留 Cloud11 `TEACHER_FIDELITY_NOT_ESTABLISHED`，不改阈值、不重训、不接 V。

## 固定对象

- Qwen3-14B revision `40c069824f4251a91eefaf281ebe4c544efd3e18`，BF16 / CUDA / eager，TF32 off、确定性计算、seed 42801，原 Tokenizer。
- 已训练的 5120→8→1 判断模块 SHA `e4c6beb1c4398085b6e292e6b3e966b35ca1469796d8a771ff481a01833896d5`；RMS、训练中心/尺度、精确 GELU、权重不变。模块输出 probability > 0.5 启用，否则拒绝。
- 只读零编号 Block13 输出，固定前缀末 Token `return`，尚未提供构造器答案。
- 原 8B 模块、阈值、全部 V Bank 及历史产物只读。本包不含 Bank，无 Bank Value 调用。

## 八个固定条件

布尔取反 N 为已知失败诊断对象；字符串转小写 N 为正确拒绝对照。两题本身都要求返回后增删，期望拒绝 R2。

每题：训练措辞 / 原留出措辞 × 无围栏 / ` ```python\n ` 围栏，共八个条件。措辞逐字复制 Cloud11；同题固定相同函数签名、缩进和裸代码正文，唯一格式差异是围栏前缀。所有真实 Token ID、绝对位置、原自然输出来源见 `data/inputs.json`。

人工提供代码前缀是受控诊断，不声称是新自然生成。无完整生成、无强制类型输出、无新增老师采样。任务标签仅用于离线解释，不进入读出模块。两道题均为已见开发题，不统计泛化率或重新判定旧实验通过。

## 主计算路径与重放

采用原真实在线分块：一次完整 Prompt Prefill，然后逐个提供已冻结代码前缀 Token；最后 `return` Token 才捕获状态。禁止把整个前缀批量算完当作相同 Cached 路径。

每个条件独立空缓存。在最后一步前保存全部 KV；clone 两份做相同 Cached 只读探针重复，再在原缓存执行无 Hook 最后一步。保存原始数组后，要求 Logits、hidden 重复逐元素一致、probe/native Logits 及全部 KV SHA 一致、父缓存未被探针改变、独立内存、Hook 清理和位置不变量通过。

4 个条件与旧自然历史 Token 完全相同，要求与旧 `decision.npz` 的 hidden/Logits 及旧末步全部 KV SHA 逐元素/哈希一致。否则 `REFERENCE_NOT_REPRODUCED`，先停止机制归因，不放宽标准。冻结模块重算旧分数误差 ≤1e-12。

所有 Cached 条件结束后才做同历史 Fresh 诊断，记录 hidden/Logits max、RMS、相对 L2、argmax 与模块决定翻转。遵循 Cloud11 Cached 主路径政策，Fresh 不替换 Cached，也不将旧 BF16 跨路径误差改成新成功。缺失或不稳定的 Fresh 必须报告；不能声称跨路径稳健。

主路径非有限值 STOP_NUMERICAL_PRIMARY；Hook/缓存/位置/SHA失败 STOP_ENGINEERING；未完成条件 INCOMPLETE。保存失败证据后停止，不反复运行至通过。

## 冻结分析定义

远端只采集；取回 SHA 验证并关机后，CPU NumPy 使用冻结模块计算：原始 5120 维 → RMS归一化 → 原训练中心/尺度 → 8维线性输入 → GELU → 最后线性输出 logit → sigmoid 分数。不得用本次数据拟合任何中心、方向、阈值或新分类器。

每题四格 logit 记为 L_train,bare、L_heldout,bare、L_train,fenced、L_heldout,fenced。

- 裸代码措辞效应：L_heldout,bare − L_train,bare。
- 围栏代码措辞效应：L_heldout,fenced − L_train,fenced。
- 两种措辞下的格式效应：L_word,fenced − L_word,bare。
- 交互：上述两种措辞效应之差。
- 全部同时报告原始分数、0.5固定阈值决定、0 logit距离。绝对 logit变化 ≥1仅标记描述性明显变化，不用作新接受阈值，不作显著性证明。
- 在各阶段记录余弦、最大差、RMS和相对L2；末层8项贡献精确算术分解，不能称作Transformer语义因果消融。

如果固定格式换措辞即翻转，支持措辞变化足以影响该诊断；固定措辞加围栏即翻转，支持格式/位置组合影响；两者叠加才翻转，报告共同变化与交互。各效应可以共存。任务间结果不一致保留，不选有利题。

围栏会增加 Token 并改变绝对位置；措辞也改变长度和内容。本实验不隔离纯位置、纯长度或关键词语义，不能将结论归因为围栏单个字符。固定前缀也可能偏离该 Prompt 自然轨迹；这是已登记的诊断限制。

## 数据保护、成本与运行

前后核验模型/Tokenizer文件 SHA、参数版本及冻结包；本地核验所有 `data/source_sha.json` 历史文件与旧 Bank SHA。实际输入不加规则文字；不装包、不下载模型、不清理旧目录。

预计原始 KV 与重复 Logits 为数百 MB 内（动态以实测为准）；本轮只保存八个位点，不保存完整回答。远端/本地各保留3GiB可用空间门槛，依据8个最多512 Token历史下的 BF16→FP32 KV、压缩存档及取回峰值冗余预留，非效果参数调整。GPU空闲≥40GiB、主机内存≥40GiB，沿用原软件版本。计算超时1200秒，安全关机兜底2700秒；证据取回校验成功即提前关机。不创建/启动实例。

只有用户另行通知开机后才能运行。失败也取回证据；不覆盖重跑。启动器已包含结果 SHA 校验、自动关机和本地固定读出分析；取回失败保留远端证据，不删除。关机仅在已确认独占实例时执行，SSH不可达不等同计费API确认。
